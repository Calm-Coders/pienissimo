GitHub organisation is theirs; Pienissimo has no commit access to this
repository.

The convention answers **who wrote something and which side they are on**. It
says nothing about whether a given change was minuted or reviewed — and in this
project several were not, which is why
[the repository runs ahead of the trackers](objects/The%20build%20ahead%20of%20the%20record.md).
That is a record-keeping gap, not an attribution problem.
